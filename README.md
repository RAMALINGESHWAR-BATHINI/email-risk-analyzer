# email-risk-analyzer
Python-based email scanner to detect suspicious email patterns and phishing indicators.

## Overview
This project analyzes email content and detects suspicious or potentially harmful messages.

The program identifies:
- Urgent language
- Suspicious links
- Sensitive data requests
- Phishing-related keywords

Based on analysis, emails are marked as:
- Safe
- Suspicious

## Features
- Keyword detection
- Link analysis
- Risk classification
- Cybersecurity awareness


## Technologies Used
- Python
- Regex
- String Processing
